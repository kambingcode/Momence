# Momence: web

The UI, API and video composition (Remotion) for Momence. For installation, API keys, running the
web app with the worker, and end-to-end tests, see the [root README](../README.md).

```bash
npm run dev        # http://127.0.0.1:3000
npm run test:e2e   # Playwright: web + a real worker on temporary data (port 3100)
```
